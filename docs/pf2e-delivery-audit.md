# PF2e delivery and contact audit

Force Barrage previously stopped its 1.867-second missile video after 300ms and its contact after 180ms. Several launch spells had no travel stage; empty native target text sent some contacts to the caster. Line spells fell back to local casting cues or unrelated breath artwork.

This revision adds 97 explicit description-based delivery mappings. Every affected description was read in full, including delayed outcomes, later attacks, action choices and heightened behavior. All 26 native line entries received an explicit treatment. Existing reviewed rays, Force Barrage, Magic Missile, Needle Darts and descending lightning retain their own motifs. No Eskie code was copied.

The complete pinned catalog has **1994 entries**: 1991 available full descriptions and three empty descriptions (Mindscape Shift, Open the Wall of Ghosts, Transmigrate). The source hash/length and media-duration audit checks every entry. **This is a focused delivery review, not a claim that every one of 1,994 descriptions was manually read or every animation was watched.** The catalog now contains 211 explicitly authored entries; remaining entries use full-description semantic rules. [Pinned official PF2e source](https://github.com/foundryvtt/pf2e/tree/563fd52708673ddd4f66c76921efbf6a938fffed/packs/pf2e/spells).

## Playback changes

- Force Barrage shows three complete overlapping flights, launched 300ms apart, with separate readable contacts around each arrival and restrained caster/target reactions. Three is an editable three-action, rank-one illustration. Total plays distribute through target order, instead of multiplying the volley by target count. Customize both flight and contact play counts for action/heightened choices; up to 18 plays supports the 15-shard high-rank example. Exact arbitrary shard allocation remains manual.
- Native flight footage stretches between origins and destinations; local glob/object artwork moves as a projectile. Baked flights are never moved twice. Generated flight/contact clips play once per planned instance.
- Actual footage duration prevents premature truncation. Contact detection excludes invisible RGB values in transparent pixels, uses an alpha-weighted destination estimate, and uses frame-reviewed arrival for the selected Magic Missile clip. Other estimates are not a claim of frame-by-frame tuning for every asset, distance or variation.
- Preview instances seek to their shared clock when browser frames arrive late. Highlights, motions, flight and impact keep the same timeline instead of starting delayed clips at zero.
- Thunderstrike and Sudden Bolt place descending lightning at the target's landing point. Thunderstrike uses a centered sonic ring rather than directional thunderwave footage. Lightning Bolt, Enervation and Radiant Beam extend through the selected native line. Lightning Lasso now connects caster and foe before crackling contact; binding conditions still depend on the save.
- Arrow Salvo now includes complete arrow flights into its burst. Force Rain uses its remote square rather than caster-only cues. Calcium Rain uses explicitly symbolic falling fragments. Updraft lifts and settles targeted token artwork; Earth and Sky lifts only caster artwork. Qi fabric uses a local Strike/contact instead of a ranged projectile.
- Target-local claws, maws, shadows and adjacent vines no longer fly from caster. Winter Bolt's next-turn explosion, Blood Chestnuts' later tree growth, Massacre's conditional return and later Aqueous/Scorching Blast attacks are not played unconditionally on initial casting.
- Line endpoints and width come from measured rays or one rectangular PF2e Region. Stationary rocks, ice, dust and leaves are separately sized along the line, capped at 24 cues; they are never distorted into rays. Beheading Buzz Saw uses disc footage, while light barriers use wall footage. Unavailable exact artwork stays labeled symbolic. Force Rain accepts one axis-aligned square Region or measured rectangle; its private footprint retains the selected square. Multishape/irregular Regions and full five-link Asterism need custom placement.
- Temporary preview footprints stay client-local and are removed on completion, errors, Stop and teardown. Existing scene areas are preserved. Motion remains cosmetic and restores the original pose. Saved user recipes are not overwritten.

## Validation

All 1,994 default recipes preflight against both inventories: 6,944 planned stages per edition, **zero missing assets**, and zero detected geometry violations. Selected inventories use 287 Patreon keys across 114 families and 182 Free keys across 115 families. Installed Patreon files were verified. Free definitions/fallbacks were audited; actual Free-pack playback was not watched.

All **204 automated tests pass**. Regressions cover total volley routing across one to four targets, a 15-shard editable volley, contact links, delayed outcomes, empty target text, hyphenated keys, one-shot footage, alpha-aware contact detection, late browser frames, line endpoints/width, Region rectangles and local preview cleanup. Native motion pacing and shared-configuration audits remain active. Rendered installed-media checks verified Force Barrage flight/contact, Thunderstrike landing and Lightning Bolt's line. Deterministic QA waits for a presented video frame before pausing. Canceling pending playback no longer produces a false unavailable-asset badge. The native Foundry server was offline during this final check, so live canvas playback is not claimed.

## Rebuild

Catalog generation uses installed `ffprobe` and `ffmpeg` to measure footage. Runtime playback uses the generated metadata and requires neither command.

```powershell
rtk proxy node tools/build-pf2e-catalog.mjs
rtk proxy node tools/build-spell-sounds.mjs
rtk proxy node tools/audit-spell-delivery.mjs
rtk proxy node tools/audit-animation-media.mjs
rtk proxy node tools/verify-spell-catalog.mjs
rtk npm test
```
