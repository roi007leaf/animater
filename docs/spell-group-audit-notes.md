# Spell group description review

All 1,994 source descriptions were checked for matching hashes and lengths. Thirty-six complete descriptions were individually read for this inspection; examples below establish that several shared bodies represent materially different spells. This is a diagnostic review, not a claim that every shared group has already received new choreography.

## Confirmed examples

| Shared body | Description differences | Current result |
| --- | --- | --- |
| Animal Form / Ooze Form / Snake Fangs | Animal battle form; dissolution into slurry; a local jaw/teeth morph | Same energy-field and sparkle body in both editions. Animal Form and Ooze Form also share pulse motion. |
| Detect Magic / Clairaudience / Sure Strike | Detection pulse; remote listening ear; preparation for a later attack | Same source-centered detection/seal body in both editions. Clairaudience lacks its remote listening treatment. |
| Lay on Hands / Regenerate / Raise Dead | Touch vitality; ongoing organ/wound restoration; returning a dead creature's soul | Same healing burst and cure-wounds body in both editions. These need distinct context, not different rank sizes. |
| Befitting Attire / Dismantle / Flame Barrier | Illusory clothing; disassembling an object; deflecting incoming fire | Same shield intro and loop in both editions. This is a semantic mismatch, not merely related protection spells. |
| Illusory Scene / Hypnotize / Phantasmal Calamity | Programmed scene; hovering mesmerizing patterns; mental disaster vision | Shared prismatic body in both editions, with native burst shape retained. Native radius differences alone made no new main design. |
| Summon Animal / Summon Construct / Summon Instrument / Summon Undead | Different creature materials, plus an instrument appearing in the caster's grasp | Same portal cue in both editions. Creature selection remains mechanical, but arrival materials and instrument treatment should differ. |
| Chilling Spray / Cone of Cold / Howling Blizzard | Icy shards and frost coating; rushing cold; winds plus lingering snow/ice terrain | Same cone-of-cold footage in both editions. Howling Blizzard also has a three-action burst option, which needs context beyond a single base recipe. |
| Polar Ray / Ray of Frost | Air and sleet ray; simpler icy ray | Same ray body in both editions. Similar ray footage is reasonable, but the stronger spell lacks its described sleet layer. |
| Cauterize Wounds / Soothing Mist | Fire sealing bleeding wounds; enveloping restorative mist | Patreon has different aura footage; Free substitutes cure-wounds for both, producing identical bodies. |
| Magnetize / Paralyze | Attraction of metal weapons/projectiles; blocked motor impulses | Patreon colors differ; Free resolves both to the same field and energy strands. |
| Dust Storm / Frozen Fog / Sanguine Mist / Solid Fog | Cutting dust; moving cold mist; draining blood fog; movement-impeding fog | Patreon differentiates them. Free collapses the main materials to the same mist treatment. |
| Enervation / Spiritual Torrent | Void beam; vitality or void torrent depending on the caster | Free shares the line body. The vitality version requires polarity-aware material/context instead of relying on a dark-beam fallback. |
| Tiny Wings / Vapor Form | Familiar grows wings and flies; creature becomes amorphous vapor | Same feathers body and levitate motion in Patreon, same wind body in Free. Vapor Form is missing vapor imagery. |

The exhaustive duplicate lists and all 38 theme counts are in [spell-group-audit.md](spell-group-audit.md). Actual edition keys for representative pairs were inspected, not inferred from asset labels.
