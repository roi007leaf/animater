# PF2e native aura variety review — 2026-10-07

Scope: all **114** state entries with native Aura rules or links to emitting providers, including **59** emitting effect documents. Complete native effect descriptions and linked spell, feat/equipment descriptions were read against pinned PF2e 8.5.1 sources. Broader non-aura statistical effects remain themed/symbolic; D&D catalogs were not redesigned in this change.

Before: 14 entries selected one blue shield loop; 12 selected one orange flame loop. Neutral fields frequently selected static token borders. Full shared form statistics led Air/Earth Element Embodied to fire footage; the word “Burn” led the force-based Life Burn Aura to flames. Runtime source lookup selected the first same-slug Aura rule, allowing base Kinetic Aura to hide a more specific active stance.

After: **88 two-layer field compositions in each edition**, plus conditional Thermal Nimbus and Manifest Will designs. Different abilities have no identical full-file compositions, and no identical layer structures when colors, tints, labels, opacity, timing and radius are ignored. Five initially color-only differences were redesigned with different texture/shape combinations. Builder rejects unrelated structural duplicates. Same-ability emitter/recipient aliases remain intentionally shared and are listed in `data/pf2e-state-catalog-audit.json`.

Literal graphics unavailable in JB2A remain disclosed approximations: butterflies symbolize Form a Flock's dragonets; grey metal fragments symbolize Spike Stones; cold/water orbit symbolizes Sea Glass Guardians. Nonvisual leadership, oaths, statistical wards and mental fields use deliberate symbolic geometry. No animation asserts an attack, save result, mechanical transformation, continuing damage tick or healing event before PF2e produces it.

Native prepared `actor.auras` controls actual reach and predicates. Prepared transmitted-effect parents select specific contributors when PF2e merges same-slug auras. Multiple contributors can retain distinct designs at the final native radius. Provider UUIDs now use native `equipment-srd`, `feats-srd` and `spells-srd` pack IDs. Recipient overlays never propagate emitter radius. All field layers attach to the same token, retain one source lifetime, and end together. Native documents, visibility and custom recipes remain authoritative.

The updated combined media audit reports zero cutoff/early-fade findings and all 1,920 selected Patreon paths installed. Free paths were checked against official/reference media; Free is not installed here. Editor rendering checked glyph ward, wind cloak, final shield sphere and thermal-choice controls, with no console errors. Native lifecycle integration uses fixtures; live multiplayer canvas remains unverified.
