## Selection and review method

The full-native scanner checked literal rays/flights, counts, material/colors, primary area, recipients, sequence order and generic shared motifs. It nominated 82 concrete suspects. Each whole description was read, including heightened, outcome-dependent, Sustain and later-turn branches. Five additional full reads followed audio/reference crosschecks: Boots on the Ground, Canticle of Everlasting Grief, Enthrall, Fortissimo Composition, Rune of Observation.

Geometry gates precede semantic ranking: radial local cues are not stretched missiles; actual beams support rays, object movies support moving rubble/blades, cone films use native cone apertures. Every authored recipe is checked in both editions using the actual first available selection. A fitting available authored motif root now takes priority over generic theme roots, while invalid geometry remains rejected. This corrected a semantic hole that a zero-geometry-error result could not detect.

The meaningful-variety metric excludes labels, IDs, sound, insignificant millisecond/rank-scale differences and inactive tint; it preserves media/roles, direction, target selection, repeats, motion, filter/entrance directions and quantized active tracks. Family choreography additionally removes exact color/file variants. These are configuration metrics, not judgments that every movie looks different or every spell has exact art.

## Verification and practical limits

- Targeted source regressions cover native phase boundaries, literal colors, count/direction/arrival, authored-root selection in both editions, unreadable references, wall compatibility and troop target requirements. Initial semantic tests reproduced failures before implementation; the asset regression specifically reproduced Fire Seeds selecting fireball before corrected roots/ranking.
- Fresh full-inventory checks confirm acorn point art, masked surface sheen, spectral skull smoke and rust particles in both editions. The canonical entire-catalog audit checks all 1,994 entries against the pinned source and both complete edition inventories.
- Media scale, alpha/gain, authored entrances, one-shot cutoffs, preview cleanup and all sounds are parent/peer-owned shared evidence. Earlier alpha exceptions (Day's Weight, Runic Body, Siege Weapon's Blessing, Void Warp) retain explicit formation/contraction rationale in the prior report; old totals are not asserted as this pass's final measurement. No threshold/exclusion was changed to make those flags disappear.
- Rendered installed-media browser/editor checks and native compiled hook/runtime tests are separate parent validation. **Live Foundry canvas and multiplayer playback were not available this pass**, and every complete animation was not manually watched. Programmatic geometry/filename validation is not a visual guarantee.
- Tiny art, real-world objects, remote summon destinations, army troops, flexible walls, mile-scale weather, elevated volume, future attacks and heightened/player choices still need native context/manual customization. Exact native outcomes are never claimed from cosmetic motion.
